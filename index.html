Missões

BOLA: vazamento de dados

  1. Faça Login e clique em Usar este token.
  2. Descubra seu ID com GET /api/me.
  3. Veja suas faturas: GET /api/faturas.
  4. Ataque: em GET /api/faturas/<id>, troque o número e tente ler a fatura de outra pessoa.

BOPLA: virar administrador

  1. Use PATCH /api/users/me.
  2. Na aba Body, faça uma alteração legítima: {"nome": "Seu nome"}.
  3. Ataque: acrescente um campo que o site nunca manda, como "role": "administrator".
  4. Confirme com GET /api/me. Depois tente achar a rota escondida de admin.
